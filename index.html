Found something wrong?

Schedules change. Each result links directly to its original listing. If a meeting has moved, closed, or changed hours, please verify with the fellowship and report the correction.

After publication on GitHub Pages, each listing will also have a Report a problem link for our public issue tracker. You will need a free GitHub account to submit a report; no account is needed to search meetings.

Privacy first: Please don't include attendee names, recovery status, phone numbers, or other sensitive personal details in public reports.

Independent community resource. Not affiliated with, sponsored by, or endorsed by any recovery organization.

Meeting details come from their source directories and may change without notice. Confirm with the source before attending. No accounts, advertising, or analytics are required to use the finder. GitHub Pages and linked sites may maintain their own server logs.

Corrections and removal requests: use the reporting links on meeting cards once this site is published on GitHub Pages, or submit changes through the original fellowship directory. We review requests and remove disputed listings while they are being checked. Do not post private attendee information.
